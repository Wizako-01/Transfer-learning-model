Explainable Multi-Class Classification of Pulmonary Diseases (Nigerian CXR Dataset)
This repository contains the implementation of three Deep Learning architectures (DenseNet-121, ResNet-50, and EfficientNet-B0) designed to classify Chest X-rays into four classes: Normal, Pneumonia, Tuberculosis, and COVID-19.

The study specifically addresses the scarcity of radiologists in Nigeria and focuses on reducing AI bias by using local clinical datasets.
